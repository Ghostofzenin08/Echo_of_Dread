ENGINEERING & SYSTEM TOPOLOGY

Echo of Dread is architected for zero external asset bloat, absolute mathematical determinism, and instant web loading.

⚡

Sub-Frame Trajectory Interpolation

The ActionRecorder records player coordinates, orientations, and interactions every physics tick. Replay utilizes a binary search interpolation algorithm guaranteeing that Echoes never desynchronize or drift across 50+ playback cycles. 

# ActionRecorder Binary Search Frame Interpolation
var low := 0
var high := frames.size() - 1
while low <= high:
    var mid := (low + high) / 2
    if frames[mid].t < target_t:
        low = mid + 1
    else:
        high = mid - 1
🔊

Procedural Audio Synthesizer

No massive audio WAV banks. The SoundManager synthesizes procedural waveforms in real-time, dynamically modulating an AudioEffectLowPassFilter (20,000 Hz down to 900 Hz) whenever loop time falls below 5.0 seconds. 

# Low-Pass Filter Emergency Urgency Modulation
var urgency_ratio := clampf((5.0 - remaining_t) / 5.0, 0.0, 1.0)
var target_cutoff := lerpf(20000.0, 900.0, urgency_ratio)
AudioServer.get_bus_effect(sfx_bus, 0).cutoff_hz = target_cutoff

GLSL Rewind & Aberration Shader

Custom GLSL fragment shader simulating screen curvature, CRT scanline phosphor decay, and high-frequency RGB chromatic aberration during temporal collapse events. 

// GLSL Temporal Rewind Chromatic Aberration
vec2 uv = SCREEN_UV;
float r = texture(screen_texture, uv + vec2(aberration, 0.0)).r;
float g = texture(screen_texture, uv).g;
float b = texture(screen_texture, uv - vec2(aberration, 0.0)).b;
COLOR = vec4(r, g, b, 1.0);
